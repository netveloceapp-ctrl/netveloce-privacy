Politique de Confidentialité - NetVeloce

Dernière mise à jour : 9 novembre 2026

Bienvenue sur NetVeloce. La protection de vos données personnelles est notre priorité. Cette politique de confidentialité explique quelles informations nous collectons, comment nous les utilisons et comment nous les protégeons.

1. Informations que nous collectons

Pour fournir nos services de diagnostic réseau, nous pouvons collecter les informations suivantes :

  • Données de compte : Lorsque vous créez un compte, nous collectons votre adresse e-mail via notre fournisseur d'authentification sécurisé (Google Firebase).
  • Données de diagnostic réseau : Lorsque vous lancez un test de débit, nous mesurons la vitesse de téléchargement, d'envoi, la latence et la gigue.
  • Adresse IP : Votre adresse IP publique est utilisée pour contacter le serveur de test et identifier votre Fournisseur d'Accès à Internet (FAI). Elle n'est pas stockée de manière permanente.
  • Données Wi-Fi locales : L'application peut lire des informations sur votre connexion Wi-Fi (comme le RSSI ou la fréquence) pour la carte de couverture (Heatmap). Ces données restent stockées localement sur votre téléphone.

2. Utilisation des données

Vos données sont utilisées uniquement pour :

  • Vous permettre de vous connecter et de sécuriser votre compte.
  • Générer vos rapports de diagnostic (PDF/CSV) que vous pouvez partager avec votre FAI.
  • Afficher votre historique de tests.

3. Partage des données

Nous ne vendons, n'échangeons et ne transférons pas vos informations personnelles à des tiers. Nous utilisons uniquement Google Firebase pour l'authentification sécurisée et le stockage des comptes.

4. Stockage local

L'historique de vos tests de débit et vos paramètres de l'application sont stockés directement sur votre appareil (base de données locale Room). Nous ne téléchargeons pas cet historique sur nos serveurs.

5. Vos droits

Vous pouvez supprimer votre compte et toutes les données associées à tout moment directement depuis l'écran des paramètres de l'application.
